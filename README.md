# Java CAPTCHA Generator

## About the Project
This is a simple Java application that generates random CAPTCHA codes using letters and numbers.

## Technologies Used
- Java
- Java Swing
- Java AWT

## Features
- Generates random 5-character CAPTCHA codes.
- Displays CAPTCHA as an image.
- Adds random lines and dots to the CAPTCHA image.
- Provides a simple graphical interface.

## How to Run
1. Download the project files.
2. Open the project in a Java IDE.
3. Compile and run CaptchaGenerator.java.

## Purpose
This project was developed to understand Java programming, random number generation and GUI development.
